How it works

Terminals — pick an agent, a count, a folder, and an optional mission. DEPLOY spawns that many live agent terminals in a workspace tab. A pane glows amber only when its agent is actually asking you to confirm something.

Board — a task queue. Each card is a task + an agent + a folder. Dragging a card into In Progress (or ▶) launches that agent in that folder with the card text as its first prompt; when the agent's terminal exits, the card moves itself to Review. It's the hands-off way to run work — Terminals is the hands-on way.

Shared memory — every board-dispatched agent is told to read/write notes in the shared memory folder so parallel agents learn from each other.

Permission bypass — when on, each agent starts with its skip-permission flag so it won't stop to ask. Turn it off per agent below if you want the prompts back.
